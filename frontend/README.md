# z3t/frontend

This is the frontend workspace of the [Z3T](https://z3t.fun) project.

It is built with ReactNative/Expo and meant to support web, iOS, and Android.

## Getting Started

```sh
pnpm install
pnpm start
pnpm android    # test in android device
pnpm ios        # test in iOS device
pnpm web        # test in browser
```
